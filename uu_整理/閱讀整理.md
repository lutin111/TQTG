# TQTG 研究紀錄：閱讀整理

整理日期：2026-09-21  
來源：`uu.md.zip` 內的 `未命名文件.md`。原文完整保存在 [原始內容.md](原始內容.md)。

這份文件將原始對話依研究脈絡重排，合併重複說明，將後續修正放在相應主題中。文內的數值是**原紀錄報告的模擬或計算結果**，本次未重新執行那些程式；原文的「PASS」「FROZEN」也只是當時研究紀錄的狀態。這是文稿整理，不是外部文獻查證或理論驗證。

## 1. 先讀這一頁：整份紀錄在研究什麼

TQTG 的核心問題是：能否從最小的交換結構，透過封裝界面、守恆量與場方程，得到可計算、可辨識的有效作用？

原文主幹可整理為：

**交換結構 → 封裝界面 → 荷與能量的讀出 → 場 → 力。**

研究同時沿幾條路展開：

| 路線 | 主要問題 | 原文走到哪裡 |
| --- | --- | --- |
| 母帳與顯化 | 正負能、電荷如何記帳，哪些部分進入場方程？ | 有顯化函數框架；母帳正負號與不同版本仍需統一 |
| 三條場論橋接 | 如何接到 Einstein、Maxwell 與額外向量場？ | 有探索版公式與內部狀態表，尚有活動性與精度關卡 |
| Orbit-Force | 額外徑向力能否在軌道資料中被辨識？ | 力空間有殘差，但位置擬合可大量吸收；長弧結果待數值收斂確認 |
| 粒子譜與 Hessian | 內部離散模式能否區分不同粒子？ | 指定徑向模型僅報告一個束縛模，轉向角向與界面模式 |
| 負膜與引力源 | 界面能、負能與排斥作用是否同一件事？ | 後文已分開處理能量、應力與 active source |
| 最小梯度模型 | 正負總量抵消時，局部勢與力是否仍存在？ | 有解析 toy model；與 KN 的尺度對應仍是候選假設 |

**文末的最新焦點**是「密度 → Poisson 勢 → 勢梯度 → 力」，以及用指定正質量積分固定最小模型的振幅。它是研究增量，不能把前面所有路線一併視為已閉合。

## 2. 基本概念與記帳方式

### 2.1 交換、封裝與外部讀出

原文以二態交換與顯／隱重排為底層圖像，再引入封閉區、界面及外部讀出。黑洞與質子被用作封裝的類比；這些類比的作用是組織研究問題，不能當成兩者已有同一微觀推導。

前時空層的帳本與後續含有位置、密度、應力的實作層應分開：何時引入空間座標、體積 measure 與時空幾何，本身就是待說明的橋接。

### 2.2 母帳與顯化帳

原文中段採用：

\[
E_{\mathrm{mother}}=E_++E_-,\qquad
E_{\mathrm{eff}}=\chi_+E_++\chi_-E_-,\qquad 0\leq\chi_\pm\leq1.
\]

若正側完全顯化，則寫成 \(E_{\mathrm{eff}}=E_++\chi_-E_-\)。核心語句是：**母帳守恆，顯化比例可以改變；隱藏不等於不存在。**

但原文後段又採用 \(E_+=|E_-|\) 的零總量模型。它與先前「母帳非零」不能直接合併，必須先分清：signed 總量、正負量的絕對值總和、顯化量，是否指同一個系統。

來源：原文 L1096–1434、L3831–3951、L4989–5109、L9759–9801。

### 2.3 光子、糾纏與電荷的支線

- 光子與「太極結構量子單元」的對照，是模型語言的探索，尚未建立兩者的完整映射。
- 糾纏部分以不可分割的整體帳本作類比，並保留 no-signalling 限制；不應將其寫成可傳遞超光速訊息。
- 「各封閉區內部電荷為零」與「外部讀出非零」需要區分兩種電荷的定義及界面關係，不能把同一物理量直接寫成同時為零、非零。

來源：原文 L3235–4081、L4403–4862。

## 3. 場方程、指紋與原有基準

早期彙編包含 SU(2) 慣例、背景 profile、Hessian、交換宇稱、平移零模投影，以及三類無單位指紋：

| 指紋 | 代表內容 | 用途 |
| --- | --- | --- |
| 結構 | 累積電荷、半徑比、形狀因子 | 比較 profile，不急著固定絕對尺度 |
| 譜 | 本徵頻率與頻率比 | 尋找穩定且有活動性的模式 |
| 場 | 場的距離依賴與斜率 | 比較近場差異與遠場極限 |

三條橋分別為：

1. **Einstein：**由總能量密度及徑向、切向壓力組成應力能量張量。
2. **Maxwell：**將拓撲流映射為電磁流；基本電荷 normalization 的微觀來源仍未完成。
3. **額外向量場 \(X_\mu\)：**以質量項與源流建立候選有效場；頻率、活動性和尺度的對應仍須驗收。

原文早期狀態表將 \(\omega_X\) 列為等待 \(J_T\)-activity，\(\beta_T\) 列為 NOT YET FROZEN；因此後文口語「繼續凍結」宜讀作**暫停賦值或更新**，不能當成已通過定值驗收。

原始公式有大量匯出重影與上下標混亂。此處只保留可清楚辨識的結構；完整技術式保留於原文，避免憑排版猜出新的係數。

來源：原文 L1212–1434。

## 4. Orbit-Force：力空間與位置空間要分開

### 4.1 探針模型

\[
\mathbf a_T=a_T(r)\hat{\mathbf r},\qquad
a_T(r)=A_T\frac{(r/R_0)^2}{1+(r/R_0)^2}.
\]

示例參數：\(A_T=10^{-10}\,\mathrm{m/s^2}\)、\(R_0=3.0\times10^7\,\mathrm m\)、半長軸 29600 km、偏心率 0.16、弧長 7 天。這是該路線的 toy probe，文件未建立它與後段負膜模型之間的完整推導。

### 4.2 OF-P1：力空間投影

後文將諧波相位由 \(nt\) 修正為 \(\Delta u=u-u_\odot\)。本次記錄使用的七參數形式為：

\[
\begin{aligned}
a_D&=D_0+D_{2c}\cos2\Delta u+D_{2s}\sin2\Delta u,\\
a_Y&=Y_0,\\
a_B&=B_0+B_{1c}\cos\Delta u+B_{1s}\sin\Delta u.
\end{aligned}
\]

| 擬合基底 | 原文報告的 RMS 力殘差比例 |
| --- | ---: |
| 七參數 ECOM2，修正相位後 | 67.5% |
| 再加 D 方向 1/rev | 23.2% |
| 再加 B 方向 2/rev | 3.9% |
| D/B 一般 Fourier 諧波至 4/rev | 0.9% |

原先「主要由 B 的 1/rev 吸收、殘差約 10–30%」的預估已被後面的紀錄修正。當時幾何下，D 方向的 1/rev 缺項更關鍵，B 的常數項也比最初預期重要。

純徑向原始力沒有軌道法向 N 分量。擬合後的 N 殘差可能來自基底幾何，不能單獨視為模型固有指紋。

### 4.3 OF-P2：軌道積分與參數聯合擬合

| 七天模型中的處理 | 位置 RMS |
| --- | ---: |
| 完全未擬合的軌道差 | 約 355 mm |
| 只擬合初始六維狀態 | 約 25.9 mm |
| 初始狀態固定，只擬合 ECOM2，非線性傳播 | 約 6.08 mm |
| 初始狀態與 ECOM2 聯合擬合，修正收斂後 | 約 0.864 mm |

最後一組另報告最大殘差約 3.61 mm，R/T/N 的 RMS 約為 0.792／0.304／0.161 mm。

因此，**力空間未被完全吸收，不等於位置資料中就容易辨識**。軌道積分、初始條件及經驗參數共同改變可辨識性。早先的 26 mm 與這裡的 355 mm 屬於不同處理層級，不宜直接比較。

### 4.4 OF-P3a 與 OF-N0：長弧結果仍待驗收

| 弧長 | 原文報告的 post-fit RMS |
| --- | ---: |
| 1 天 | 1.05 mm |
| 3 天 | 1.17 mm |
| 7 天 | 1.50 mm |
| 14 天 | 1.28 mm |
| 30 天 | 6.58 mm |

這是另一輪弧長掃描，應保留自己的設定與流程，不與 OF-P2 數字混成同一次實驗。後續提出起始相位掃描，以及 OF-N0：步長收斂、零額外力的 Kepler 控制、Richardson 外推與 post-fit 收斂檢查。

目前可保留的研究問題是：較長弧段的絕對殘差能否通過數值檢查，並超過實際觀測和模型誤差？原文不構成真實衛星資料中的檢出。

來源：原文 L1761–2493、L3003–3180、L4104–4370。

## 5. 固定點、粒子分類與 Hessian

### 5.1 交換固定點

最小對稱交換模型寫出：

\[
\eta_E^*(\varepsilon)=\frac{\varepsilon+\sqrt{\varepsilon^2+4}}2,
\qquad\varepsilon=\gamma_H/\gamma.
\]

將它與形態臨界曲線相交，是原文探索的固定點路線。黃金比例的出現仍需要獨立推導交換率等參數，不能把反解所需參數當成對黃金比例的預言。此段的負側量是帶符號能量還是正的幅值，也需要統一。

### 5.2 粒子分類的修正

原文先試圖用 \(B\) 的正負區分電子／質子，後來由對稱性審查修正：

- \(B\to-B\) 管理電荷共軛；在當時對稱模型中，質量相關的偶扇區不變。
- 不同物種須來自內部模式、複合拓撲、界面條件等額外結構。
- \(Z_-\) 被當成 profile 與讀出 kernel 的泛函，尚未得到完整粒子質量譜。

### 5.3 徑向本徵問題的結果與限制

原文建立廣義本徵問題 \(H_T\psi_n=\omega_n^2W_T\psi_n\)。在其指定的 \(\alpha_T=1.68\)、繞數 1 模型中報告：

- 最低本徵值 \(\omega_0^2\simeq0.84495\)。
- 連續譜門檻 \(\omega_{\mathrm{cont}}^2\simeq1.19048\)。
- 擴大計算盒子後，只有最低模穩定留在門檻以下，其餘低階數值模往門檻靠近。

所以「三個徑向束縛模對應 e／μ／τ」在這個最小實作中沒有成立。後續改研究角向／界面模式，並要求二分量 Hessian、平移零模與歸一化二階變分檢查。這不等於完整模型的全部穩定性已通過。

來源：原文 L5628–5817、L6004–7147、L7251–7505。

## 6. E₂、E₄、E₀ 與負膜：保留後文修正

原文採用 \(E=E_2+E_4+E_0\) 的實作，分別討論 bulk stiffness、quartic/interface stabilization、vacuum restoring。其尺度變分寫為：

\[
E(\lambda)=E_2+\lambda^2E_4+\lambda^{-2}E_0,
\qquad E_4=E_0\quad\text{於所述尺度平衡點}.
\]

後文強調：**尺度穩定的平衡，不等於引力正負源相抵。**

在原文所選的 2D→3D 嵌入與應力約定下，後續分類為：

| 扇區 | 後文的角色 | 不應混淆的地方 |
| --- | --- | --- |
| E₂ | 後續逐項推導中為非負 active source | 取代較早「混合正負」的暫定說法 |
| E₄ | 界面／拓撲穩定及各向異性應力；該組式子的 active scalar 為零 | 有能量、有應力；不能直接叫負質量，也不能說完整四維張量跡為零 |
| E₀ | 該組式子中的負 active source | 真空型壓力效應與 signed 負能不同 |
| E₋ | 真正 signed 負側帳本的候選來源 | 仍須給出自身張量或狀態方程 |

所用標量為：

\[
\rho_{\mathrm{active}}=\rho+\frac{p_r+2p_t}{c^2}.
\]

這些分類是特定實作下的研究紀錄，不能直接推廣成所有 E₄ 模型的普遍結論。完整引力問題仍須使用總應力能量張量。原文亦將 \(\alpha_T^{\mathrm{crit}}\approx1.68\) 降回舊粗粒化實作的形態候選值，等待重新計算。

來源：原文 L7618–7856、L8892–9364。

## 7. 文末主線：最小梯度模型

### 7.1 先分清密度梯度與勢梯度

原文後來固定的鏈為：

\[
\rho_+,\rho_-\longrightarrow\rho_T=\rho_+-|\rho_-|
\longrightarrow\nabla^2\Phi_T=4\pi G\rho_T
\longrightarrow\mathbf g_T=-\nabla\Phi_T.
\]

密度梯度描述源分布如何變化；實際力場在這個模型中由勢梯度給出。局部密度零點、累積質量零點、力的極值是不同位置。

### 7.2 可清楚還原的解析式

對 \(A>0,R>0\)，文末使用：

\[
\rho_T(r)=A\left(1-\frac{2r^2}{3R^2}\right)e^{-r^2/R^2},
\]
\[
M_T(<r)=\frac{4\pi A}{3}r^3e^{-r^2/R^2},
\qquad g_T(r)=-\frac{4\pi GA}{3}r e^{-r^2/R^2},
\]
\[
\Phi_T(r)=-\frac{2\pi GAR^2}{3}e^{-r^2/R^2},
\qquad\Phi_T(\infty)=0.
\]

其重點是總 signed 質量在無窮遠為零，但有限半徑可以有非零勢與場。對上述正振幅，有限正半徑的累積質量為正、徑向場向內；局部負密度並不自動代表該處的總場向外。

特徵位置：

\[
r_{\rho=0}=\sqrt{3/2}\,R,\qquad r_{|g|\max}=R/\sqrt2.
\]

### 7.3 振幅 normalization

若另外指定正密度區的積分質量 \(M_+=M\)，則：

\[
I_+=\int_0^{\sqrt{3/2}}x^2(1-2x^2/3)e^{-x^2}\,dx
=\frac{(3/2)^{3/2}e^{-3/2}}3
\simeq0.1366387596,
\]
\[
A=\frac{M}{4\pi I_+R^3}\simeq0.5823931054\frac{M}{R^3}.
\]

本次整理重算了這兩個純數係數，與原文近似值一致。這表示**在已選 profile、尺度及 M 定義之後**，振幅可被固定；它沒有自行消除那些建模假設。

### 7.4 KN 尺度對應仍有兩個版本

原文定義：

\[
r_g=GM/c^2,\qquad a=J/(Mc),\qquad
r_Q^2=GQ^2/(4\pi\varepsilon_0c^4).
\]

但 R 出現兩個選擇：

| 版本 | 定義 | 整理時的處理 |
| --- | --- | --- |
| 較早候選 | \(R=\max(r_g,\sqrt{a^2+r_Q^2})\) | 保留為尺度候選 A |
| 文末版本 | \(R=\sqrt{a^2+r_Q^2}\) | 保留為尺度候選 B；與 A 在部分區域不同 |

採用 A 時 \(R/r_g\geq1\)，不能照搬版本 B 的 \(R/r_g<1\) 分類；採用 B 時，零自旋、零電荷給出 R=0，不能直接代入上述正 R 的平滑模型。兩者必須先選清楚。

此外，M 同時用於 KN 幾何及正密度積分，而 toy model 的總 signed 質量為零；需要交代它們的物理對應。因此原文「完全接上 KN」「無自由參數、完全閉合」在整理版中保留為**尚待驗證的主張**。

來源：原文 L9759–9877、L10281–10334、L10581–10692。

## 8. 接續研究時優先處理的事

1. **統一記號與版本：**明確區分 signed 能量、能量幅值、顯化量、質量密度、active source；選定 R 的版本及 M 的意義。
2. **固定最小梯度模型的定位：**它是獨立解析探針，還是要從 soliton profile 推導？原文兩條路都出現過。
3. **補齊物理橋接：**若走完整引力路線，建立守恆的總張量及邊界條件，而不只做尺度配對。
4. **保存軌道實驗的可重現條件：**不同 OF-P 結果分別記錄模型、相位、擬合參數、步長和誤差；完成 OF-N0 後才判讀長弧增長。
5. **粒子譜先過模式關卡：**檢查角向與界面束縛模、零模和活動性，再討論質量比。
