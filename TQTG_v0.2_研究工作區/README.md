# TQTG v0.2 研究工作區

建立日期：2026-09-18。狀態：研究設計草案，尚未成為新的物理驗證版本。

這個資料夾把 v0.1 的缺口整理為可追蹤、可否證的研究工作。核心材料維持 \(E_+,E_-^{mag},Q,\mathcal T\)；候選數學結構是「路」，不是新增的已證明本體。

本次完成原文核對、研究規格與驗收設計，沒有執行原 runtime、推導完整 QED 或新增物理 PASS。

## 從這裡開始

1. 閱讀 [基線與紅線](01_基線與紅線.md)，確認什麼已由原文件報告、什麼仍缺證據。
2. 閱讀 [研究路線圖](02_研究路線圖.md)，按依賴順序推進。
3. 優先填妥 [待解問題與執行收據](08_待解問題與執行收據.md) 的基線交接欄位，再進行數值工作。

## 使用規則

- `SOURCE_REPORTED`：原文報告的結果，本工作區未獨立重現。
- `PROPOSED`：候選規格或新推導方向。
- `NOT_RUN`：尚未執行。
- `BLOCKED`：缺少明確前置資料或依賴。
- `PASS` / `FAIL`：只用於有收據、適用範圍與預先設定判準的具體檢驗。

新的測試只證明收據所列命題，不自動升級成「光子湧現」「電子推導」或「理論成立」。
