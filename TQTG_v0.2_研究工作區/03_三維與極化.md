# 03 三維與極化

狀態：PROPOSED；依據 PDF §§10–17、42、61。沒有建立新 Hamiltonian。

## 要回答的問題

在保留局部交易與守恆的前提下，是否能構造三維傳播模型，並在低能區得到兩個物理橫向模態？把 scalar 直接換成 vector 只增加分量，不自動產生 Maxwell 結構。

## 候選表示與必要定義

一條待評估路徑是採用定向格點複形：節點承載電荷、邊承載候選場／通量、面承載旋度量。先定義离散梯度 G、旋度 C、散度 D，檢查可組合的 incidence operators 滿足 CG=0、DC=0，並分開寫清 primal／dual 網格及度量映射。

這種表示可能有助於保留離散恆等式，但不是 TQTG 已推導出的規範理論。必須逐一提供：

1. 每個變數由四料帳或 \(\mathcal T\) 的哪個量表示。
2. 正則配對、局部更新及所需的 Hamiltonian 定義。
3. 電荷連續性與候選 Gauss 約束；帶電情況不能一律設 divergence 為零。
4. 若使用 gauge redundancy：等價類與可觀測量；若不使用：如何一致去除非物理模態。
5. 約束的初始滿足條件與時間保存證明。
6. 三維候選的 1D reduction 如何對接既有 runtime；不吻合之處要明列。

上述任一結構若是直接借用 Maxwell，必須標為外部輸入，不稱為湧現。參見 [標準自由電磁場與極化](https://www.damtp.cam.ac.uk/user/tong/qft/qfthtml/S6.html)。

## 檢驗規格

| 檢驗 | 觀測 | 失敗訊號 |
|---|---|---|
| 離散一致性 | CG、DC 與邊界處理 | 邊界或內部破壞聲稱的恆等式 |
| 約束保存 | 初始與每步約束殘差 | 隨時間不受控增長 |
| 守恆與穩定 | E、p、Q、transit、場幅 | 帳務不閉合或不受控不穩定 |
| 模態計數 | 非零波向量的低能物理模態 | 額外低能縱向傳播模態 |
| 方向測試 | 軸向、面對角、體對角 | 各向異性在低能／細化時不減弱 |
| 有限尺寸與細化 | 多個盒尺寸和格距 | 把有限盒 gap 或格點 artifact 誤認成物理 |

「兩個極化」指合適非零波向量下的物理傳播態；零模與邊界模另行審計。只有先固定 branch identity，才可擬合色散；不得為得到漂亮直線挑選分支。

## 本階段允許的結論

最多宣告「特定三維候選在指定參數下通過若干傳播與約束測試」。Lorentz 相容性、continuum Maxwell matching 和完整 photon 身分都需要額外證據。
