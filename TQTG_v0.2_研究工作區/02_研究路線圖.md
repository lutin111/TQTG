# 02 研究路線圖

狀態：PROPOSED。下列 R 編號是本資料夾的研究關卡，不是原文 Gate 2A–2H 的改名或後續 PASS。

## 路線選擇

可採三種尺度：只整理概念、先做可重現的最小模型、同時建立完整三維量子理論。本工作區採「先完成基線交接，再研究最小可檢驗構造」：前者不足以驗證物理，後者依賴太多尚未定義的結構。

| 關卡 | 交付 | 前置 | 目前狀態 |
|---|---|---|---|
| R0 基線交接 | 原碼、環境、收據、雜湊、符號表 | 原始材料 | BLOCKED：未提供 runtime |
| R1 一維重現 | 含失敗 rollback 的守恆回歸紀錄 | R0 | NOT_RUN |
| R2 三維候選設計 | 局部變數、更新式、約束、1D 對應 | R0 及明確的新路徑定義 | PROPOSED |
| R3 動量與應力 | 單元平衡、邊界通量與符號測試 | R2 | PROPOSED |
| R4 傳播資格 | 分支、有限尺寸、色散、無能隙與極化 | R2，且沿用既有光譜審計順序 | NOT_RUN |
| R5 量子與物質結構 | 狀態空間、么正演化、spinor、費米統計 | R2 及量子構造 | PROPOSED |
| R6 尺度穩定性 | 粗粒化映射、完整耦合流、\(\Xi\) 審計 | 明確微觀模型及可識別的 s、t | PROPOSED |
| R7 外部匹配 | 振幅、vertex、截面、可觀測量比較 | 相關資格成立，且明確解除原有暫停 | BLOCKED：QED matching 暫停 |

R3、R5、R6 可以進行概念研究，但不能因設計文件完成而宣告其物理依賴已過關。R6 不是所有 3D 工作的前置，也不是單獨重啟 Phase II 的充分條件。

## 首個具體里程碑

先交付 R0 的「可重現基線清單」：程式入口、依賴版本、\(H\)、\(\psi_0\)、初始化、邊界、步長、轉換／sink／rollback 規則、receipt 與 samples。

取得資料後，先重現一個成功交易與一個強制失敗交易，逐項對帳能量、動量、電荷及 transit。這是建議的最小重現範圍，不可冒充正式 Full Run。

## 完成標準

v0.2 可以先是一個「完成指定數值關卡的研究版本」，無須宣稱完整理論。版本發布應列出已跑／未跑項目、適用維度、參數範圍，以及哪些量是外部輸入。數值一致性、數學推導和實驗驗證分別記錄。
