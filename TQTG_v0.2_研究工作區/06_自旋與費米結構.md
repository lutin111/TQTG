# 06 自旋與費米結構

狀態：PROPOSED。原文 §45 的方向是 closed exchange → P_t → angular momentum structure，仍待推導。

## 四個不可混淆的量

| 結構 | 必須建立的證據 |
|---|---|
| 迴圈／繞數 | 配置空間、等價關係與拓撲不變量 |
| 角動量 | 旋轉生成元及其守恆條件 |
| 量子自旋 | 狀態在旋轉下的表示與 Casimir |
| 費米統計 | 多粒子交換的反對稱規則 |

前一列不自動推出下一列。兩個不同問題都需要驗證：單粒子的旋轉性質，以及多粒子態的交換性質。

## 候選推導的必要步驟

先明定封閉交換網路的配置空間與量子態空間，再定義空間旋轉 R 如何作用為 U(R)。若目標是自旋，檢查生成元

\[
[J_i,J_j]=i\hbar\epsilon_{ijk}J_k.
\]

若目標是電子的自旋部分，需出現 \(J^2=\tfrac34\hbar^2\) 的表示。在適當 spinor 表示上，2π 旋轉給出負號、4π 恢復；單次整體相位負號本身不能替代相對相位或表示結構的檢验。[旋轉與 spinor 表示](https://www.damtp.cam.ac.uk/user/tong/qft/qfthtml/S4.html)

電子候選還須建構多粒子態與交換作用。不能只給每個 package 貼上「fermion」標籤；若反對易關係是採用的公設，明記為輸入。自旋統計定理具有其相對論量子場論前提，不能未驗前提就援引為 TQTG 結論。[Dirac 場量子化與統計](https://www.damtp.cam.ac.uk/user/tong/qft/qfthtml/S5.html)

## 檢驗與停止條件

- 配置繞數改變的障礙是否定義清楚；是否依賴人為固定邊界。
- 有限旋轉的組合律與生成元代數是否一致。
- 能否區分軌道角動量與內稟部分。
- 兩個同種粒子交換、相同單粒子態佔據及與成對產生末態是否一致。
- 若只得到整數自旋或純經典環流，不能稱電子自旋已完成。

soliton 的穩定點、整數拓撲荷與 Photon-0 交易鏈保持獨立；沒有映射證據以前不互相補強。spin 幾何化可以是長期路徑，並非所有 3D 守恆工作都必須先完成它。
