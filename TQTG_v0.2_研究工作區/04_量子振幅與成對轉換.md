# 04 量子振幅與成對轉換

狀態：PROPOSED。原文 Gate 2A–2H 是守恆交易證據鏈，不是散射振幅推導。

## 先分開三個層次

1. 運動學：轉換是否符合能量、動量、電荷與末態質量條件。
2. 動力學：允許的通道具有什麼複數振幅，以及如何相互干涉。
3. 測量：振幅如何給出機率、轉換率與截面。

在採用標準相對論粒子接口且 \(c=\hbar=1\) 時，兩光子到電子正電子的必要閾值為

\[
\mathsf{s}=(k_1+k_2)^2\ge4m_e^2.
\]

此處 \(\mathsf{s}\) 是 Mandelstam 不變量，與 RG 文件中 f(x) 的係數 s 不同。對 runtime 局部 convertible 四動量能否套用此接口，必須先驗證其定義與適用性；閾值不是振幅，也不保證轉換發生。

## 最小量子構造

須提供狀態空間、內積、可觀測量、複數相位的來源與合成規則。若選擇封閉系統演化 U，檢查 \(U^\dagger U=I\)。候選振幅可記為

\[
\mathcal A_{fi}=\langle f|U|i\rangle,
\]

但這只是待實作的定義，不是由 \(\mathcal T\) 自動推導。若使用開放系統或測量通道，須交代環境與機率保存，不能直接用條件接受率取代封閉系統么正性。

測試至少包括：歸一化、改變相對相位造成的可預測干涉、逆過程的相容性，以及失敗交易不憑空重複計入振幅。rollback 只保證程式狀態復原，不保證量子演化合法。

## 缺少的物質場與 vertex

電子／正電子 package 的質量及電荷標籤，不等於電子量子場。要得到物理截面，仍需末態 spinor、費米交換規則、相互作用 vertex、態的歸一化與動量相空間。

在上述標準散射接口成立後，才可使用

\[
d\sigma=\frac{\overline{|\mathcal M|^2}}{
4\sqrt{(k_1\cdot k_2)^2-m_1^2m_2^2}}\,d\Phi_2.
\]

橫線的初態平均／末態求和取決於指定極化配置；不能把非極化公式混用於極化結果。此式是外部 QFT 比較接口，非 TQTG 的新推導。[振幅、通量與截面](https://www.damtp.cam.ac.uk/user/tong/qft/qfthtml/S3.html)

## 驗收與否證

- 僅有實數隨機權重、沒有相位與干涉：只能稱隨機交易模型。
- 同一組固定參數下，先比較閾值，再比較角分布、極化依賴與能量依賴；不能每個能點分別調參。
- 借用 QED vertex 或電子質量時，標記為輸入，不能再當作獨立預測。
- 格距、時間步長及樣本量改變時，記錄截面估計的系統誤差與統計誤差。
- QED matching 尚未開放；本文件只準備接口與驗收規格，不開始匹配。
